# Iconos PWA

Estos son iconos **temporales de desarrollo**, generados programáticamente
(fondo `#0b7d7d` / brand-600, ícono de escudo + lente en blanco) para que
el manifest tenga archivos reales y el navegador no solicite recursos
inexistentes al instalar la PWA.

- `icon-192.png` — 192×192, purpose "any"
- `icon-512.png` — 512×512, purpose "any"
- `icon-maskable-512.png` — 512×512, con safe zone del 50% de radio (dentro
  del 80% central) para máscaras Android, purpose "maskable"

## Reemplazo antes de producción

Antes de publicar, sustituir por el logo real de la empresa con las mismas
dimensiones. Herramienta sugerida: https://realfavicongenerator.net o
exportar desde el logo en Figma/Illustrator.

Color de fondo recomendado para el "safe zone" maskable: `#0b7d7d` (brand-600).
